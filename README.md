# Bellei e Peres — sistema de conteúdo para o Instagram

Pasta operacional do projeto Adapta Native do escritório Bellei e Peres Sociedade de Advogados.
Aqui ficam somente a fase em andamento, as entregas, as notas e o código do sistema.

Repositório: https://github.com/drkgod/bellei-peres (público, branch `main`).

## Fase atual

**Fase 1 — Da pauta ao carrossel aprovado no Instagram** · 19/10/2026 a 30/10/2026

- [Tarefas da fase](04_fase-atual/fase.md) — 36 tarefas (7 principais e 29 subtarefas), as mesmas do portal.
- [SPECs da fase](04_fase-atual/specs/00-INDICE.md) — 7 especificações com critérios de aceite e testes.

Ordem de execução: 1-001 → 1-003 (prova de conexão até 21/10) → 1-002 → 1-004 → 1-005 → 1-006 → 1-007.

## Como trabalhar

1. Abra a próxima tarefa em `04_fase-atual/fase.md` e a SPEC correspondente.
2. Construa com o Maestro **uma tarefa por vez**, no projeto do sistema no Skip.
3. Rode os testes da SPEC e faça o teste humano descrito nela.
4. Só marque `[x]` quando a prova e o teste humano estiverem feitos. Não apague os marcadores `<!-- id:… -->`: eles ligam cada linha ao card do portal.
